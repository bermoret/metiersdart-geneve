# Projet Beacode

Ce dossier est un projet Beacode. Beacode LIT tout le dossier, mais n'ÉCRIT que
dans `Beacode/` (sauf le code, édité en place). Arbre à la demande :

- `code/` — le code du projet (édité en place, à la racine)
- `Beacode/documents/` — documents (studio Document)
- `Beacode/presentations/` — présentations (studio Présentations)
- `Beacode/data/` — tableurs & dashboards (studio Tableur)
- `Beacode/meetings/` — enregistrements et transcriptions de réunions
- `Beacode/sources/` — fichiers ajoutés à la base de connaissance
- `Beacode/knowledge/`, `Beacode/memory.md` — index de connaissance et mémoire

Tout le dossier sert de base de connaissance. Le code n'est pas indexé : il est
lu à la demande.
